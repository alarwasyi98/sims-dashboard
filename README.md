## Getting Started

Clone this repository to run locally

```sh
git clone --depth=1 https://github.com/alarwasyi98/sims-dashboard.git
```
Install required dependencies. [`npm`](https://nodejs.org/en) recommended. Start development server then.

```bash
npm install
```

```bash
npm run dev
```

> [!INFO]
> Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
